# Brainbox Gig AI Privacy Notice

Last updated: September 9, 2026

Brainbox Gig AI is a browser extension for Fiverr sellers. This notice explains what the extension processes.

## Data processed

The extension may process:

- Fiverr gig and profile page content needed to generate or optimise text.
- Search result information used for local market research, such as visible gig titles and prices.
- Information the user enters into the extension, such as profile details, skills and gig niches.
- API credentials entered by the user for Anthropic or Groq.
- Locally saved draft recovery data and extension preferences.

## AI providers

When the user chooses an AI feature, the relevant prompt and necessary page or profile context may be sent directly from the extension to the AI provider selected by the user, currently Anthropic or Groq. Brainbox does not operate an intermediary AI server for these requests.

Users should review the privacy terms of their selected AI provider and should not enter secrets or sensitive information into prompts unless they understand the provider's handling of that data.

## Storage

Extension settings, API credentials and recovery data are stored using browser extension storage. API credentials are stored in Chrome extension storage and are not intentionally transmitted to Brainbox-owned servers.

## Fiverr pages

The extension runs on Fiverr pages because its core purpose is to assist with Fiverr gig and profile creation. Market research reads visible Fiverr search results and may use Fiverr's own search/autocomplete endpoints in the user's browser session.

## Draft recovery

Draft Recovery stores a local copy of visible form fields in extension storage so users can recover work after a page problem. Users can clear this data by clearing the extension's stored data.

## Advertising and affiliate disclosure

The current release does not include Google AdSense or other third-party advertising code. If advertising or affiliate functionality is added in a future release, the store listing and this notice will be updated before that functionality is shipped.

## Data sale

Brainbox Gig AI does not sell extension data.

## Contact

For privacy questions or requests, contact the maintainer through the GitHub repository associated with Brainbox Gig AI.
